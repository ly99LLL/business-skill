## 🎯 这是什么？

**Business Skill** 是一个 [Claude Code](https://claude.ai/code) 的定制技能（Skill）。它能把你的：

- 💡 灵光一现的脑洞

…转化为**结构化、可执行、具有社会价值**的商业方案。

## 📦 安装

### 方法一：一键安装（推荐）

**Windows PowerShell:**
```powershell
git clone https://github.com/ly99LLL/business-skill.git $env:USERPROFILE\.claude\skills\business-skill
```

**Mac / Linux:**
```bash
git clone https://github.com/ly99LLL/business-skill.git ~/.claude/skills/business-skill
```

### 方法二：使用安装脚本

**Windows:**
```powershell
.\install.ps1
```

**Mac / Linux:**
```bash
chmod +x install.sh && ./install.sh
```

### 方法三：项目级安装

```bash
# 在特定项目目录下
mkdir -p .claude/skills
git clone https://github.com/ly99LLL/business-skill.git .claude/skills/business-skill
```

## 🎮 使用方法

在 Claude Code 中输入 `/business-skill`，然后分享你的任何想法。

### 🎯 基础用法

```
/business-skill 我注意到小区里的老人们每天早上都会聚在一起做操，
但他们用的是手机外放，声音很小，经常听不清。这能做成生意吗？
```

### 🧠 进阶玩法

| 命令 | 效果 |
|------|------|
| `/business-skill 给我一个灵感` | 随机生成5个创意组合激发灵感 |
| `/business-skill 生成BP` | 基于之前的分析输出完整商业计划书 |
| `/business-skill 分析我的技能` | 个人技能资产盘点 + 4条变现路径 |
| `/business-skill 从这个角度再分析` | 切换视角深度分析 |
| `/business-skill 对标[某公司/品牌]` | 调取对标案例，借鉴模式 |

### 🌟 输入示例

```
💡 灵感："能不能做一个帮人挑选礼物的AI？"
😄 趣事："今天看到一个小孩用电话手表给奶奶唱歌，特别可爱"
😤 痛点："每次搬家找靠谱的搬家公司都要花半天时间比价"
🔭 趋势："最近身边好多人在用AI做副业赚钱"
🎒 资源："我是做了5年的UI设计师，业余想搞点副业"
🌍 议题："社区里的独居老人越来越多了，怎么帮他们？"
```

## 🌟 价值观（不可妥协）

我们坚信：**好的商业，让世界更好。**

因此本skill内建了以下十项原则：

| # | 原则 | 说明 |
|---|------|------|
| 1 | 🕊️ **诚实透明** | 好坏都分析，不画大饼，不隐藏风险 |
| 2 | 🌍 **可持续发展** | 优先推荐绿色、低碳、循环经济方案 |
| 3 | 🤝 **包容多元** | 考虑不同人群的需求，主动消除偏见 |
| 4 | ⚖️ **合法合规** | 红线不碰，灰色不推 |
| 5 | 💝 **用户价值为本** | 不割韭菜，不搞套路，不利用信息差 |
| 6 | 🏔️ **长期主义** | 鼓励十年磨一剑，反对昙花一现 |
| 7 | 🔒 **隐私至上** | 数据变现必须保护用户隐私 |
| 8 | 🎯 **公平竞争** | 不推荐垄断、恶意竞争、掠夺性定价 |
| 9 | 🧠 **反对成瘾设计** | 不利用人性弱点的成瘾机制 |
| 10 | 🌱 **代际公平** | 考虑对下一代的影响 |

> **"想法不值钱，把想法变为现实的能力才值钱。"**

大多数人有了想法后的路径：

有了 Business Skill 后的路径：
```

看清价值、市场、路径 → 知道明天该做什么 → 开始行动
```

**这就是有skill和没skill的区别。**
