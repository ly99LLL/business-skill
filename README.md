## 📖 项目简介

**Business Skill** 是一个为 [Claude Code](https://claude.ai/code) 打造的**世界级商业化思维引擎**——一个将日常灵感、生活观察、痛点发现转化为结构化、可执行、具有社会价值的商业方案的 AI 技能（Skill）。

它不是你常见的"商业计划模板填充器"，而是一个**模拟顶尖商业顾问团队的智能系统**。它融合了麦肯锡的结构化思维、Y Combinator 的创业实战方法论、IDEO 的设计思维、丹尼尔·卡尼曼的行为经济学、ESG 可持续发展理念以及孙子兵法的竞争战略——在你输入任何一个想法的瞬间，它便启动 **12 层深度分析框架**，并同时切换 **6 种角色视角**（投资人、用户、竞争对手、社会观察者、行为科学家、未来学家）为你提供 360° 无死角的商业可行性评估。

无论你是：
- 💡 脑中闪过一个创业点子的**独立创客**
- 😤 在日常生活中遇到痛点想寻找商机的**产品经理**
- 🔭 关注趋势想要把握先机的**投资人**
- 🎒 盘点自己的技能想拓展副业的**职场人**
- 🌍 关注社会议题想用商业手段解决问题的**社会创新者**

…Business Skill 都能帮你把模糊的想法，变成一个**知道明天该做什么**的清晰方案。

**核心能力一句话总结**：输入一个想法，得到一份包含市场规模、商业模式、财务估算、竞争策略、MVP 路线图、风险评估、社会影响以及 6 个独立角色评分的完整商业分析报告。

## 💭 创作缘由

在信息爆炸的 AI 时代，**想法本身变得越来越廉价**——每个人每天都能产生无数个"我觉得可以做个 XX"的念头。但真正的问题在于：

> **"想法不值钱，把想法变为现实的能力才值钱。"**

大多数人的创意旅程是这样的：

```
有一个想法 → 觉得不错 → 不知道从哪里开始 → 搁置 → 遗忘
```

这个"想法死亡漏斗"每天都在吞噬着无数潜在的商业创新。究其原因，不是想法本身不好，而是**缺乏一套系统化的思维框架**来帮助普通人：
1. **验证**这个想法是否真的值得做
2. **看清**市场的全貌和竞争格局
3. **规划**从 0 到 1 的可执行路径
4. **预见**可能的风险和伦理问题
5. **获得**多角度的独立反馈

传统的解决方案——找咨询公司、报创业课、读商业书籍——要么太贵，要么太慢，要么太理论化。而现有的 AI 工具（ChatGPT 等）虽然能给出商业建议，但缺乏**结构化深度、角色多元性、价值观约束和行业特化能力**。

**Business Skill 应运而生**——它不是一个简单的"提示词模板"，而是一套完整的**商业思维操作系统**。它把世界顶级商学院、咨询公司和加速器的核心方法论，编码成了一个任何人都能随时调用的 AI 技能。

## ✨ 创作灵感

这个项目的诞生，本身就是一个"跨界连接"的结果——它来自以下几个灵感的碰撞：

### 🎯 灵感 1：YC 的"办公时间"
Y Combinator 的合伙人会在每周的"办公时间"与创业者进行 15 分钟的高强度对话，用精准的问题帮助创始人看清方向。我想：**能不能把这种能力编码成一个 AI 技能，让任何人都能随时获得这种级别的反馈？**

### 🧠 灵感 2：查理·芒格的"多元思维模型"
芒格一生推崇用多学科的思维模型来分析问题。他说："拿着锤子的人，看什么都像钉子。"我想：**如果一个 AI 技能内建了行为经济学、竞争战略、设计思维、ESG 等多元模型呢？**

### 🎭 灵感 3：六顶思考帽
爱德华·德·波诺的"六顶思考帽"方法——有意识地切换不同思维角色来审视同一个问题。我想：**如果 AI 能同时模拟投资人、用户、竞对、社会观察者、行为科学家和未来学家的视角呢？**

### 🌍 灵感 4：商业向善运动
Patagonia、Whole Foods 等企业证明了**利润和社会价值可以兼得**。我想：**为什么不在商业分析的最底层就内建可持续发展和代际公平的价值观呢？**

### 🤖 灵感 5：Claude Code 的 Skill 机制
当 Anthropic 推出 Claude Code 的自定义 Skill 功能时，我突然意识到：**这就是承载这套思维框架的完美载体**——它可以做到即插即用、全球安装、零配置启动。

这五个灵感的交汇，最终凝结成了 **Business Skill v2.0**。

## 🔥 核心特性

### 🔬 十二层深度分析框架

每一层都是经过精心设计的分析模块，层层递进、环环相扣：

| 层次 | 名称 | 核心命题 | 关键产出 |
|------|------|----------|----------|
| **第1层** | 价值锚点 | 为谁创造了什么价值？ | JTBD、痛点强度评分、5 Whys、创始人-市场匹配 |
| **第2层** | 用户心理与行为 | 用户在想什么？如何做决定？ | 认知偏差映射、决策旅程、情绪曲线、习惯循环 |
| **第3层** | 市场引力 | 这个市场值得进入吗？ | TAM/SAM/SOM 数字估算、市场阶段诊断、浪潮vs风潮 |
| **第4层** | 商业模式画布 | 这个生意怎么赚钱？ | 9要素完整分析（价值主张→成本结构） |
| **第5层** | 定价与财务 | 能赚钱吗？赚多少？ | 单位经济学（CAC/LTV）、三年财务快照、盈亏平衡 |
| **第6层** | 蓝海创新 | 如何跳出红海竞争？ | ERR框架（消除/减少/提升/创造）、价值曲线 |
| **第7层** | 竞争与护城河 | 怎么防止被抄袭？ | 护城河评估、竞对矩阵、波特五力、防御策略 |
| **第8层** | MVP路径 | 如何用最少资源最快验证？ | MVP类型选择、30/60/90天路线图、资源清单 |
| **第9层** | 增长引擎 | 如何系统化增长？ | 北极星指标、AARRR海盗指标、病毒循环设计 |
| **第10层** | 风险与韧性 | 什么会杀死这个项目？ | 风险矩阵（6类）、黑天鹅情景、反脆弱设计 |
| **第11层** | 社会影响与伦理 | 这个生意让世界更好了吗？ | SDG对齐、隐私安全、可及性、代际公平 |
| **第12层** | 故事与传播 | 这个故事讲得通吗？ | 电梯演讲三版本、情绪钩子、品牌人格 |

### 🎭 六角色深度模拟

每个想法都会经过 6 个独立角色的审视，每个角色给出独立的量化评分和专业判断：

| 角色 | 视角 | 核心关注点 | 输出格式 |
|------|------|------------|----------|
| 💰 **投资人** | 红杉/YC/天使 | 市场天花板、团队匹配、竞争壁垒、退出可能 | 投资决策（投/不投/观望）+ 估值范围 |
| 👤 **用户** | 目标用户 | 痛点真实度、替代方案、迁移成本、情感价值 | 使用意愿(1-10) + 付费意愿(1-10) |
| ⚔️ **竞争对手** | 行业老大/新锐 | 威胁程度、可复制性、差异化、收购意愿 | 威胁评分(1-10) + 应对策略 + 时间窗口 |
| 🌍 **社会观察者** | 公众利益 | 正/负外部性、公平性、可持续性、长远影响 | 社会价值评分(1-10) + 警惕点 |
| 🧠 **行为科学家** | 心理学角度 | 认知偏差、决策障碍、习惯力量、社会压力 | 核心心理驱动 + 最大障碍 + 助推建议 |
| 🔮 **未来学家** | 5年后的世界 | 技术演进、社会变迁、趋势交汇、新型态 | 3个未来演化可能 + 最大不确定性 |

### 🏭 十大行业深度模板

自动识别行业类型，调用对应的行业专属分析模板，包含行业特定的关键指标、风险清单、成功要素和创新方向：

- 🍔 **餐饮/食品** — 坪效·人效·翻台率·食安·供应链
- 🛒 **电商/DTC** — GMV·退货率·品类铁律·私域·柔性供应链
- 📱 **SaaS/软件** — MRR/ARR·Churn·Rule of 40·PMF信号
- 🎓 **教育/知识付费** — 完课率·续费率·B2C/B2B/B2G·政策风险
- 🏥 **健康/ wellness** — 临床验证·合规成本·信任周期·数据追踪
- 🌾 **农业/食品供应链** — 亩产·损耗率·产地品牌·期货/预售
- 💰 **金融科技** — 合规第一·安全至上·AI风控·普惠金融
- 🎮 **游戏/互动娱乐** — DAU/MAU·留存·ARPU·防沉迷·正向设计
- 🌿 **可持续/ESG** — 碳账户·循环经济·B Corp·生物多样性
- 🏘️ **地产/空间运营** — 坪效·出租率·社区营造·存量改造

### 🧠 行为经济学应用

内建 7 大认知偏差的产品化应用方法论：
- **损失厌恶** (Loss Aversion) — "失去的痛苦 > 得到的快乐"
- **锚定效应** (Anchoring) — "第一个数字决定一切"
- **社会认同** (Social Proof) — "别人都在用，我也要用"
- **稀缺感** (Scarcity) — "限时限量，不买就没了"
- **框架效应** (Framing) — "换个说法，结果完全不同"
- **禀赋效应** (Endowment Effect) — "一旦拥有，就不愿放手"
- **现状偏差** (Status Quo Bias) — "改变太难了，还是维持现状吧"

每个认知偏差附带**伦理使用原则**——我们教你怎么理解用户心理，但绝不鼓励操纵或成瘾设计。

## 🛠️ 技术栈

这个项目的技术选型反映了 **"内容为王，工具为辅"** 的理念——核心价值在于方法论的设计和知识的编码，而非炫技式的技术堆砌：

### 核心技术

| 层级 | 技术/工具 | 用途 |
|------|-----------|------|
| 🤖 **AI 引擎** | Claude Code (Anthropic) | Skill 运行环境，提供 LLM 推理能力 |

### 设计哲学

- **零依赖** — 不需要安装任何第三方库或运行时（除了 Claude Code 本身）
- **纯文本驱动** — 所有逻辑和知识都在 `.md` 文件中，易于阅读、修改和扩展
- **即插即用** — 一个 `git clone` 或运行安装脚本即可完成部署
- **知识可迁移** — 核心方法论与运行平台解耦，框架可被提取到其他 AI 工具中使用
- **社区友好** — Markdown 格式的文档和框架使得贡献门槛极低

## 📦 快速部署

### 前置条件

- 安装 [Claude Code](https://claude.ai/code)（Anthropic 官方 CLI）
- Git（用于克隆仓库）

### 方法一：一键克隆安装（推荐 ⭐）

**Windows PowerShell:**
```powershell
git clone https://github.com/ly99LLL/business-skill.git $env:USERPROFILE\.claude\skills\business-skill
```

**Mac / Linux:**
```bash
git clone https://github.com/ly99LLL/business-skill.git ~/.claude/skills/business-skill
```

### 方法二：使用安装脚本

**Windows:**
```powershell
.\install.ps1
```

**Mac / Linux:**
```bash
chmod +x install.sh && ./install.sh
```

### 方法三：项目级安装（仅对特定项目生效）

```bash
# 在你的项目根目录下
mkdir -p .claude/skills
git clone https://github.com/ly99LLL/business-skill.git .claude/skills/business-skill
```

### 验证安装

在终端中输入 `claude` 启动 Claude Code，然后输入：

```
/business-skill 给我一个灵感
```

如果能正常输出创意组合和分析，说明安装成功！✅

### 更新到最新版本

```bash
# 全局安装的更新
cd ~/.claude/skills/business-skill && git pull

# 项目级安装的更新
cd .claude/skills/business-skill && git pull
```

## 🎮 使用方法

### 基础用法 — 分享你的任何想法

在 Claude Code 中输入 `/business-skill`，然后描述你的想法：

```
/business-skill 我注意到小区里的老人们每天早上都会聚在一起做操，
但他们用的是手机外放，声音很小，经常听不清。这能做成生意吗？
```

### 七种输入类型 — 系统自动识别

| 输入类型 | 图标 | 示例 |
|----------|------|------|
| 灵感一闪 | 💡 | "能不能做一个帮人挑选礼物的AI？" |
| 生活趣事 | 😄 | "今天看到一个小孩用电话手表给奶奶唱歌，特别可爱" |
| 痛点发现 | 😤 | "每次搬家找靠谱的搬家公司都要花半天时间比价" |
| 趋势洞察 | 🔭 | "最近身边好多人在用AI做副业赚钱" |
| 资源盘点 | 🎒 | "我是做了5年的UI设计师，业余想搞点副业" |
| 社会议题 | 🌍 | "社区里的独居老人越来越多了，怎么帮他们？" |
| 技术应用 | ⚙️ | "AI能不能用来帮助农民预测作物病虫害？" |

### 进阶命令

| 命令 | 效果 |
|------|------|
| `/business-skill 给我一个灵感` | 🎲 随机生成5个创意组合激发灵感 |
| `/business-skill 生成BP` | 📋 基于之前的分析输出完整商业计划书（12模块） |
| `/business-skill 分析我的技能` | 🎯 个人技能资产盘点 + 4条变现路径 + 6个月路线图 |
| `/business-skill 从这个角度再分析` | 🔄 切换视角深度挖掘 |
| `/business-skill 对标[某公司/品牌]` | 📊 调取对标案例，借鉴模式 |
| `/business-skill 用[行业]模板分析` | 🏭 指定行业模板进行分析 |

## 🌟 项目意义

### 对个人的意义

**"让每个人都能获得世界级的商业顾问"**

在传统世界里，要获得这种深度和广度的商业分析，你需要：
- 付费聘请麦肯锡级别的咨询顾问（数百万起）
- 进入 Y Combinator 等顶级加速器（录取率 < 2%）
- 就读顶级商学院（学费数十万 + 2年时间）

Business Skill 让这一切**免费、即时、随时随地**可用。它把原本只属于少数精英的商业思维工具，交到了每一个有想法的人手中。

### 对创业生态的意义

**降低从"想法"到"行动"的认知门槛**

创业失败的第一大原因是"做了没人要的东西"——而这个项目正是帮你**在写第一行代码之前**，就用系统化的方法验证你的想法。

- 帮助创业者在投入时间和金钱之前获得全面评估
- 用多角色模拟弥补单一视角的盲区
- 通过行业模板降低新进入者的学习成本
- 以价值观底线引导商业向善

### 对社会创新的意义

**让"商业向善"从口号变成可操作的框架**

- SDG 对齐评估让社会影响力可量化
- 道德罗盘确保商业创新不越界
- 代际公平原则引导长期主义思维
- 包容性和可及性检查防止技术排外

### 对 AI 应用的意义

**证明了 AI 不仅是"聊天工具"，更是"思维操作系统"**

Business Skill 展示了 Claude Code Skill 机制的真正潜力——不是写一个提示词模板，而是构建一个完整的**认知增强系统**：

- 系统化的多层分析框架 > 一次性问答
- 强制性的多角色模拟 > 单一视角
- 硬编码的价值观约束 > 无原则的迎合
- 模块化的知识架构 > 松散的对话历史

## 🧠 项目对我的能力提升

开发这个项目的过程中，我在以下维度获得了显著成长：

### 1. 系统化思维能力

设计 12 层分析框架的过程，本身就是一次对自己商业知识体系的**全面梳理和结构化**。我需要回答："商业分析的完整图景是什么样的？每个层次之间是什么关系？如何让它们形成闭环？"这个过程让我从"知道很多商业概念"升级到了"拥有一个完整的商业思维操作系统"。

### 2. Prompt Engineering → Skill Architecture

这个项目让我从"写提示词"的层面跃迁到了"设计 AI 技能架构"的层面。我学会了：
- 如何设计 YAML 前置元数据来控制技能的触发条件
- 如何构建分层指令体系来保证输出的一致性和深度
- 如何使用角色扮演提示来实现真正的多视角分析
- 如何在 AI 行为中硬编码不可妥协的价值观

### 3. 知识工程化能力

将散落在头脑中、书籍里、课程笔记里的商业知识，转化为**结构化的、机器可读的、可复用的文档体系**——这是一项全新的能力。我需要思考：哪些知识适合放在核心 Skill 文件中？哪些适合作为参考手册按需加载？如何组织行业模板的结构才能平衡通用性和专业性？

### 4. 行为经济学的深度应用

为了设计用户心理分析模块，我深入研究了卡尼曼、塞勒、西奥迪尼等行为经济学大师的理论，并将抽象的理论转化为可操作的"认知偏差→产品应用→伦理边界"映射表。这不仅提升了我的分析能力，也让我对"技术伦理"有了更具体的理解。

### 5. 产品思维的进化

这个项目的用户是"有想法但不知道怎么做的人"——我需要深刻地共情他们的困惑、焦虑和决策障碍。设计 7 种输入类型识别、10 个超级功能模块、30/60/90 天路线图，本质上都是在回答一个问题：**"用户在这个阶段最需要什么？如何用最低的认知成本给他们最大的价值？"**

### 6. 开源项目运营

从 v1.0 到 v2.0 的迭代，GitHub 仓库管理、Commit 信息规范、安装脚本编写、跨平台兼容性处理——这些都是实实在在的工程能力。特别是 install.ps1 的编码问题修复，让我对 Windows PowerShell 的字符编码陷阱有了深刻的理解。

### 7. AI 伦理的实践

10 项不可妥协的价值观不是口号——在设计每一个分析模块时，我都需要问自己："这个功能可能被滥用吗？如何在不牺牲功能的前提下守住伦理底线？"这种思考方式已经内化成了我的一种工作习惯。

### 一句话总结

> **这个项目让我从一个"会用 AI 的人"，变成了一个"能用 AI 构建思维系统的人"。**
