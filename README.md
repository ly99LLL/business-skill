## 🎯 这是什么？

**Business Skill** 是一个 Claude Code 的定制技能（Skill），它能把你的：
- 💡 灵光一现的脑洞
- 😄 生活中的有趣观察
- 😤 遇到的痛点和麻烦
- 🔭 注意到的趋势变化

...转化为**结构化、可执行、具有社会价值**的商业方案。

它不是简单的点子生成器，而是一个融合了：
- 🏢 **麦肯锡**级别的结构性思维
- 🚀 **Y Combinator**的创业实战方法论
- 🎨 **设计思维**的用户洞察
- 🌍 **ESG**可持续发展理念的**完整商业思维引擎**。

## ✨ 核心特色

| 特色 | 说明 |
|------|------|
| 🔬 **七层分析框架** | 价值锚点→市场引力→商业模式→蓝海创新→MVP→增长→风险 |
| 🎭 **多角色模拟** | 投资人、用户、竞对、社会，四个视角同时审视 |
| 🧠 **反直觉洞察** | 跳出常规思维，发现隐藏的商业机会 |
| 🔗 **跨界创新** | 自动连接不同领域，激发跨界创意 |
| 📋 **BP一键生成** | 输出完整商业计划书框架 |
| ⚖️ **价值观内建** | 可持续、向善、诚信、长期主义，绝不推荐灰色模式 |

## 📦 安装

### 方法一：全局安装（推荐，所有项目都能用）

**Windows PowerShell:**
```powershell
# 克隆到 Claude Code 全局 skills 目录
git clone https://github.com/YOUR_USERNAME/business-skill.git $env:USERPROFILE\.claude\skills\business-skill
```

**Mac / Linux:**
```bash
git clone https://github.com/YOUR_USERNAME/business-skill.git ~/.claude/skills/business-skill
```

### 方法二：项目级安装

```bash
# 在项目目录下
mkdir -p .claude/skills
git clone https://github.com/YOUR_USERNAME/business-skill.git .claude/skills/business-skill
```

### 方法三：一键安装脚本

**Windows:**
```powershell
.\install.ps1
```

## 🎮 使用方法

在 Claude Code 中输入 `/business-skill`，然后分享你的想法。

### 示例

```
/business-skill 我注意到小区里的老人们每天早上都会聚在一起做操，
但他们用的是手机外放，声音很小，经常听不清。这能做成生意吗？
```

你会得到：
- 📌 价值锚点分析（谁？什么问题？为什么是现在？）
- 📊 市场规模估算（中国2.8亿老年人的切角）
- 🧬 完整商业模式画布
- 🌊 蓝海创新策略
- 🏗️ 30/60/90天MVP执行路线图
- 📈 增长引擎设计
- ⚠️ 风险与社会责任评估
- 🎭 四个角色的独立评价（投资人/用户/竞对/社会）
- 🚀 明天就能开始的3件事

### 更多玩法

| 命令 | 效果 |
|------|------|
| `/business-skill 生成BP` | 基于之前的分析，输出完整商业计划书 |
| `/business-skill 给我一个灵感` | 随机生成创意组合激发灵感 |
| `/business-skill 分析我的技能` | 个人技能商业化诊断 |

## 🌟 价值观

我们坚信：

> **好的商业，让世界更好。**

因此本skill内建了以下不可动摇的原则：

1. 🕊️ **诚实透明** — 好坏都分析，不画大饼
2. 🌍 **可持续发展** — 优先推荐绿色、低碳方案
3. 🤝 **包容多元** — 考虑不同人群，消除偏见
4. ⚖️ **合法合规** — 红线不碰，灰色不推
5. 💝 **用户价值为本** — 不割韭菜，不搞套路
6. 🏔️ **长期主义** — 鼓励十年磨一剑，而非昙花一现
7. 🔒 **隐私至上** — 数据变现必须保护用户隐私
8. 🎯 **公平竞争** — 不推荐垄断或恶意竞争
