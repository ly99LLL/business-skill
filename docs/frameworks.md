# 📚 商业分析框架参考手册

本文档详细说明 business-skill 使用的各类商业分析框架。

---

## 🔬 第一层：价值锚点分析 (Value Anchor)

### 核心问题
1. **谁**是目标用户？（越具体越好）
2. 解决**什么**问题？（痛点不是需求，痛点+付费意愿才是需求）
3. **为什么是现在**？（时机三要素：技术成熟度、市场接受度、竞争窗口）
4. **为什么是你**？（创始团队优势、独特资源、先发优势）
5. 用户愿意付**多少钱**？（定价三段论：成本参照、价值参照、竞争参照）

### 分析工具
- **JTBD (Jobs To Be Done)**: 用户雇佣这个产品来完成什么工作？
- **5 Whys**: 连续问5个"为什么"深挖根本原因
- **Pain Scale**: 1-10分，这个痛点有多痛？用户多久遇到一次？

## 📊 第二层：市场引力 (Market Gravity)

### TAM / SAM / SOM 模型

```
TAM (Total Addressable Market) — 总可触达市场
└── SAM (Serviceable Available Market) — 可服务市场
    └── SOM (Serviceable Obtainable Market) — 可获取市场
```

### 估算方法
1. **自上而下**: 行业报告数据 → 细分市场 → 你的份额
2. **自下而上**: 单个用户价值 × 潜在用户数 × 渗透率
3. **类比法**: 参考类似品类的发展轨迹

### 市场阶段判断
- 🔴 **早期市场** — 需要教育用户，但有机会定义品类
- 🟡 **成长期** — 市场快速扩大，竞争加剧，抢地盘
- 🟢 **成熟期** — 存量竞争，拼效率和差异化
- 🔵 **衰退期** — 谨慎进入，除非有颠覆性创新

## 🧬 第三层：商业模式画布 (Business Model Canvas)

### 九要素
| 要素 | 核心问题 |
|------|----------|
| **价值主张** | 我们创造什么价值？为什么用户选我们？ |
| **客户细分** | 谁是最重要的客户？他们有什么特征？ |
| **渠道通路** | 如何触达客户？线上线下？直销分销？ |
| **客户关系** | 获取、留存、增长分别怎么做？ |
| **收入来源** | 谁付钱？付多少？多久付一次？ |
| **核心资源** | 需要什么关键资源？（人、技术、品牌、数据...）|
| **关键业务** | 必须做好的核心活动是什么？ |
| **重要伙伴** | 谁是我们不能没有的伙伴？ |
| **成本结构** | 最贵的成本是什么？固定vs可变？ |

### 常见商业模式
- 📦 **订阅制 (Subscription)**: 月/年付费，稳定现金流
- 🎁 **免费增值 (Freemium)**: 基础免费，高级付费
- 🛒 **市场平台 (Marketplace)**: 连接供需，抽佣
- 📢 **广告模式 (Ads)**: 用户免费，广告主付费
- 🔌 **生态模式 (Ecosystem)**: 硬件低利润，服务高利润
- 📊 **数据变现 (Data)**: 用数据创造价值（注意隐私！）
- 🏢 **开源+服务 (Open Core)**: 开源核心，付费服务

## 🌊 第四层：蓝海战略 (Blue Ocean Strategy)

### ERR框架 (Eliminate-Reduce-Raise-Create)

| 行动 | 说明 |
|------|------|
| **消除 (Eliminate)** | 哪些被行业视为理所当然的因素可以去掉？ |
| **减少 (Reduce)** | 哪些因素可以降低到行业标准以下？ |
| **提升 (Raise)** | 哪些因素应该提升到行业标准以上？ |
| **创造 (Create)** | 哪些行业从未提供的因素可以创造出来？ |

### 价值曲线 (Value Curve)
- 横轴：竞争要素
- 纵轴：提供水平
- 目标：画出与竞争对手截然不同的价值曲线

## 🏗️ 第五层：MVP路径 (Minimum Viable Product)

### MVP三原则
1. **最小** — 只做验证假设必需的，不做"nice to have"
2. **可行** — 能真正跑通核心流程，不是demo
3. **产品** — 可以交付给用户使用，不是内部工具

### MVP类型
- 🎬 **视频MVP**: Dropbox用一段演示视频验证需求
- 👨‍💼 **门房MVP (Concierge)**: 人工手动完成服务，验证流程
- 🧙 **绿野仙踪MVP (Wizard of Oz)**: 用户以为自动化，实际是人工
- 📄 **落地页MVP**: 一个页面+购买按钮，测试转化率
- 🔩 **单一功能MVP**: 只做一个核心功能

### 30/60/90天路线图
- **30天**: 验证核心假设 → 找到10个愿意付费的用户
- **60天**: 打磨核心体验 → 周留存率达到40%
- **90天**: 找到增长杠杆 → 周环比增长20%

## 📈 第六层：增长引擎 (Growth Engine)

### 增长公式
> 增长 = 获客 × 激活 × 留存 × 变现 × 传播

### 关键指标
- **CAC (Customer Acquisition Cost)**: 获客成本
- **LTV (Lifetime Value)**: 用户生命周期价值
- **LTV/CAC > 3**: 健康的增长引擎
- **Churn Rate**: 流失率，越低越好
- **Viral Coefficient**: 病毒系数，>1则指数增长

### 增长杠杆
1. **内容营销**: 长期投入，复利效应
2. **SEO/ASO**: 让用户能搜到你
3. **付费广告**: 快速起量，但注意LTV/CAC
4. **推荐机制**: 让用户帮你拉人
5. **社区运营**: 聚集核心用户，形成飞轮
6. **BD/合作**: 借力打力，快速扩张

## ⚠️ 第七层：风险与伦理 (Risk & Ethics)

### 风险矩阵
| 风险类型 | 说明 | 缓解措施 |
|----------|------|----------|
| 市场风险 | 需求不存在/不够大 | 快速验证，小步试错 |
| 执行风险 | 团队做不出来 | 最小化MVP范围，找人 |
| 竞争风险 | 大厂/竞对碾压 | 差异化，垂直深挖 |
| 技术风险 | 技术不成熟/被淘汰 | 选择成熟技术栈 |
| 政策风险 | 监管变化 | 提前研究，合规优先 |
| 资金风险 | 现金流断裂 | 控制burn rate，尽早盈利 |

### 社会责任清单
- 是否考虑了对环境的影响？
- 是否保障了用户隐私和数据安全？
- 是否对不同人群公平可及？
- 是否创造了有尊严的就业？
- 是否避免了成瘾性设计？
- 供应链是否合乎道德？

## 🎭 多角色思维模板

### 💰 投资人关心
- TAM是否足够大？（至少10亿级别）
- 团队为什么能做这件事？
- 护城河在哪里？（网络效应、品牌、技术、规模...）
- 退出路径是什么？（IPO、并购、持续分红）

### 👤 用户关心
- 这个产品解决我的什么问题？
- 我现在怎么解决这个问题的？
- 用这个比现有方案好在哪？（至少10倍好）
- 价格值不值？

### ⚔️ 竞争对手关心
- 这个新进入者的独特优势是什么？
- 我能快速复制吗？
- 我需要担心吗？还是可以忽略？
- 是否应该收购/合作/打击？

### 🌍 社会层面
- 这个项目创造什么社会价值？
- 可能存在什么外部性（正面/负面）？
- 是否加剧或减少了不平等？
- 对环境有何影响？
